# A-Novel-Approach-for-Disaster-Victim-Detection-Under-Debris-Environments
## Overview

This project presents an AI-based approach for detecting disaster victims trapped under debris in post-disaster environments such as earthquakes, landslides, and building collapses. The system combines Deep Learning and Machine Learning techniques to analyze disaster scene images and automatically identify the presence of victims.

The primary objective of this project is to assist rescue teams by improving the speed and accuracy of victim detection, enabling more efficient search-and-rescue operations.

## Problem Statement

Locating victims trapped under debris during natural disasters is a challenging and time-consuming task. Traditional rescue methods require significant human effort and may delay emergency response.

This project aims to develop an intelligent victim detection system that can:

- Detect victims from disaster images.
- Reduce rescue response time.
- Improve the efficiency of search-and-rescue operations.
- Assist rescue teams in making faster decisions.

## Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Pandas
- Matplotlib

## Methodology

1. Image preprocessing and augmentation.
2. Feature extraction using ResNet50.
3. Feature selection and processing.
4. Classification using J48 Decision Tree.
5. Performance evaluation using classification metrics.

## Results

The proposed model demonstrates efficient victim detection in disaster environments by combining deep feature extraction with machine learning classification techniques. The system has the potential to assist rescue teams in identifying victims more accurately and efficiently.
